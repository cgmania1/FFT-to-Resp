## 실행 방법

**온라인에서 바로 쓰기: https://cgmania1.github.com/FFT-to-Resp**

내 PC에서 쓰려면 설치 없이 아래 두 방법 중 하나로 엽니다.

1. **파일로 바로 열기** — 이 폴더의 `index.html` 을 더블클릭해 크롬·엣지로 엽니다. 인터넷이 없어도 동작합니다(엑셀 라이브러리도 `vendor/` 에 들어 있습니다).
2. **간이 서버로 열기** — 폴더에서 `python3 -m http.server 8000` 을 실행하고 브라우저에서 `http://localhost:8000` 을 엽니다.

사용 순서: **1. FRF 불러오기**(엑셀 선택 → 주파수 열·응답점 열 짝짓기 → FRF 표 만들기) → **2. 계산 조건**(RPM 범위, 차수, 가진력 — 차수별 상수 / RPM 연동 벡터 / RPM별 표 파일, 필요하면 차수별 scale factor) → **3. 결과**(그래프·표·엑셀) → **4. 가진력 추정**(계측 표가 있을 때 — 형식: 차수별·overall·여러 지점(차수 우선/지점 우선)·지점별 시트·긴 형식, 방식: 따로 / scale 고정 / 다항식, 비교: 차수별·overall, 오차: 평균값·최대값). 머리행은 지점 이름을 파일 그대로 두고 차수 표기(1차 · 1 · 1st · 1X · H1 · order 1 · 1ord · ord1 · 전각 — 1/rev 는 쓰지 않아 읽지 않음)를 읽어, 계산 전에 「열 배정 확인」 표로 보여 줍니다. 알아보지 못한 머리행은 추측하지 않고 표시만 하며, 열마다 직접 고칠 수 있습니다.

처음에는 비어 있습니다. 위쪽의 **「예시 데이터 불러오기」** 를 누르면 가상 FRF·계측·가진력 표가 들어가고 「예시 데이터」 안내 띠가 표시됩니다.

- 파일과 계산은 **이 브라우저 안에서만** 처리되며 외부로 보내지 않습니다. 조건은 브라우저 저장소(localStorage)에 남고, 결과는 엑셀로 내려받아 보관합니다.
- 예시 파일(모두 가상 값): `samples/예시데이터_FRF.xlsx`·`.csv`(크기+위상, 응답점 3개), `samples/예시데이터_계측응답.csv`·`.xlsx`, `samples/예시데이터_가진력표.csv`
  - 계측 형식별(같은 값): `예시데이터_계측_1지점_차수별`·`_1지점_overall`·`_다지점_차수우선`·`_다지점_지점우선`·`_다지점_overall`·`_다지점_머리행혼합`(표기 제각각 + 차수 아닌 열) (csv·xlsx), `예시데이터_계측_지점별시트.xlsx`
- 로직 테스트: `node test/logic.test.mjs` (의존성 없음, 파이썬 교차 확인 포함)
- 파이썬 교차 확인: `python3 python/rpm_response.py samples/예시데이터_FRF.csv --point 예시_운전석바닥_진동 --orders 1,2,4 --forces 120,60,25 --rpm 800 3000 100` · 코랩용 `python/rpm_response_colab.ipynb`
  - scale factor: `--orders 1,2,4 --scales 1,0.5,0.2 --ref-order 1 --forces 120` · RPM 연동 벡터: `--force-vector 벡터.csv`
  - 가진력 추정: `--point 응답점1,응답점2,… --estimate samples/예시데이터_계측응답.csv --degree 1` (또는 `--orders … --scales … --ref-order k`)
  - 계측 형식·overall·최대 기준: `--estimate samples/예시데이터_계측_다지점_지점우선.csv --meas-format wide --layout point --meas-orders 1,2,4 --orders 1,2,4 --degree 1 --objective overall --crit max` (`--meas-format files` 는 지점별 csv 를 쉼표로, `--rel` 은 상대오차)
  - 머리행 규칙: 웹과 같은 차수 표기 정규화, 알아보지 못한 머리행은 표준오류에 이유를 적고 뺌. 파일의 지점 이름이 FRF 와 다르면 `--alias "운전석=예시_운전석바닥_진동;핸들=예시_핸들_진동"`. 코랩 노트북 5번 칸에서 머리행 인식 결과를 볼 수 있음
- 예시 파일 다시 만들기: `node scripts/make-samples.js`

## 1단계 구현 범위

기획서 5장 기능 목록 기준입니다. 수강생 확인(2026-09-28 댓글)대로 과제 B 를 먼저 만들었고, 과제 A 는 다음 단계입니다.

| 기능 (기획서 5장) | 과제 | 상태 | 1단계에서 한 것 / 남은 것 |
|---|---|---|---|
| FRF 엑셀 불러오기 | 공통 | 완료 | xlsx·xls·csv(UTF-8/CP949), 시트·머리행 선택, 주파수 열·응답점 열 짝짓기, 크기 / 크기+위상 / 실수+허수, 응답점별 단위. 정렬·중복·빈 값 경고 |
| RPM·차수 설정 | B | 완료 | RPM 시작·끝·간격, 차수 목록(소수 차수 가능), 가진력 단위 |
| RPM 조건 FRF 값 추출 | B | 완료 | 가진 주파수 = 차수 × RPM / 60 (가정), 보간 3종(선형·가장 가까운 점·로그) 선택, 해석 범위 밖은 계산하지 않고 표시 |
| RPM별 응답 계산 | B | 완료 | 차수 성분 = \|FRF\| × 가진력. 가진력은 차수별 상수 또는 RPM별 가진력 표(RPM 사이 선형 보간) |
| overall 계산 | B | 완료 | 차수별 RSS. 범위 밖 차수가 빠진 행은 「일부 차수 제외」로 표시 |
| 결과 엑셀·그래프 | B | 완료 | 응답점별 시트 + 계산조건 시트 엑셀, 응답점별 CSV, RPM-응답 곡선(세로축 로그 전환, SVG 저장) |
| 가진력 추정 | B | 완료(가정 형식) | RPM·차수별 계측 표 → 응답점별 추정값, 반공진 부근 경고(기준은 사용자 입력), 경고 없는 응답점 최소제곱 종합값, 추정 엑셀, 종합값을 가진력 표로 다시 계산에 쓰기. 실제 계측 형식(시간 신호 등)은 2단계 |
| 가진력 입력 보완 (09-29) | B | 완료 | RPM 연동 벡터(화면 입력·엑셀 붙여넣기·RPM 범위로 줄 만들기), 차수별 scale factor 로 기준 차수 하나만 입력 — F_k = (s_k/s_기준) × F_기준 |
| 가진력 추정 보완 (09-29) | B | 완료 | 계산/계측 오차 최소화: scale 고정 → 기준 차수 RPM별 크기, 미고정 → 차수별 n차(0~5) 다항식 계수(QR 최소제곱). 계수 표·RPM별 가진력 그래프·계산 vs 계측 그래프·잔차(RMS·dB)·엑셀, 추정값을 계산에 다시 쓰기. 합성 계측 복원 테스트(1e-9) |
| 계측 형식·overall 추정 (09-29 오후) | B | 완료 | 계측 표 형식 6가지(차수별·overall·여러 지점 차수 우선/지점 우선·지점별 시트·긴 형식)와 열 배정 확인 표, overall 오차 최소화(√Σ 합성 모형 → 차수별 가진력), 오차 기준 평균값(RMS)/최대값(minimax), 절대/상대오차. 예시 파일·테스트·파이썬 동일 |
| 머리행 차수 표기 정규화 (09-29 저녁) | B | 완료 | 지점 이름은 파일 그대로, 차수는 1차·1·1st·2nd·1X·H1·order 1·Ord1·전각 숫자 인식(틀린 서수 2st 등은 거부), 열 배정 확인 표에 읽은 표기·상태, 열별 직접 지정, 지점 이름 짝. 긴 형식 차수 칸·가진력 표 머리행도 같은 규칙. 테스트·파이썬 동일 |
| 차수 표기 1ord·ord1 확인, 1/rev 거부 (09-30) | B | 완료 | 수강생 답변 「1ord, ord1 등은 사용하나 1/rev는 사용하지 않음」. 1ord·2ord·ord1 (대소문자·공백·구분자·전각 변형) 인식을 명시·테스트, 「1/rev」는 머리행 구분자 「/」 때문에 「1」+「rev」로 잘못 갈라지던 것을 막고 이유와 함께 「인식 못함」. 웹·파이썬·코랩 동일 |
| 교차 확인 | B | 완료 | 같은 계산의 파이썬 스크립트·코랩 노트북(가진력 벡터·scale·추정 포함), 손계산 기대값 테스트 |
| 단위·dB 변환 | B | 다음 단계 | 기준값 확인 후 2단계 |
| 여러 가진점 합성 | B | 다음 단계 | 복소 합성 여부 확인 후 2단계 |
| Peak 검출 | A | 다음 단계 | 2단계 (과제 B 확정 뒤 여유가 있을 때) |
| 가진 주파수 ↔ 고유진동수 비교 | A | 다음 단계 | 2단계 |
| AI 판단 보조 | A | 다음 단계 | 3단계 |
| 해석 이력 비교 | 공통 | 다음 단계 | 3단계 |

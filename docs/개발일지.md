## 결정과 이유

- **계산식은 원문 그대로**입니다. 차수 응답 = |FRF| × 가진력(참고 1), overall = 차수 성분의 RSS(참고 2).
- **열은 화면에서 짝짓습니다.** 실제 FRF 엑셀의 열 배치를 아직 모르기 때문입니다. 머리행 이름으로 주파수 열·크기/위상·실수/허수 짝을 먼저 추정하고, 사용자가 고칠 수 있게 했습니다. 실제 파일이 와도 코드를 고치지 않고 맞출 수 있습니다.
- **보간 방식은 고르게 했습니다**(선형·가장 가까운 점·로그). 기획서 10장에서 방식을 확인하기로 했기 때문입니다. 로그 보간에서 0 이하 값이 끼면 그 칸만 선형으로 대신하고 경고합니다.
- **해석 범위 밖 차수는 0으로 치지 않고 빼며, 「일부 차수 제외」로 표시**합니다. 0으로 채우면 overall 이 조용히 작아지기 때문입니다.
- **반공진 경고 기준은 사용자 설정**입니다(기본 0.05 = 그 응답점 최대 |FRF| 의 5%). 기준값은 해석자가 정할 일이라 고정하지 않았습니다.
- **가진력 추정 종합값은 경고 없는 응답점들의 최소제곱**(Σ|FRF|·|계측| ÷ Σ|FRF|²)입니다. 응답점별 값도 함께 보여 줘 서로 어긋나면 알아볼 수 있게 했습니다.
- **추정값을 곧바로 「RPM별 가진력 표」로 넣어 다시 계산**할 수 있게 했습니다. 기획서 9장의 「추정 가진력으로 다음 해석 입력 신뢰도를 높임」을 한 화면 흐름으로 옮긴 것입니다.
- **그래프는 외부 라이브러리 없이 SVG 로 직접 그립니다.** 파일로 열어도(인터넷 없이) 돌고, SVG 로 저장해 보고서에 넣을 수 있습니다.
- **예시 데이터는 전부 가상 값**입니다. 파일 이름이 `예시데이터_` 로 시작하고, 화면에 안내 띠가, 내보낸 엑셀의 조건 시트에 「예시 데이터(가상)」가 찍힙니다.

## 가정 (실제 자료를 받으면 확정)

1. 차수는 회전 차수이고 가진 주파수 = 차수 × RPM / 60 입니다.
2. 주파수 열 단위는 Hz 입니다.
3. 가진점은 하나이며, 크기+위상·실수+허수여도 응답 계산에는 |FRF| 만 씁니다.
4. RPM별 가진력 표는 「한 행 = RPM, 차수마다 열 하나」 형식입니다.
5. 계측 표는 「한 행 = RPM·차수, 응답점마다 계측값 열 하나」 형식이며, 계측점 이름이 FRF 응답점과 대응합니다.
6. 응답 단위는 FRF 단위 × 가진력 단위이며 dB 변환은 하지 않습니다.

## 판단과 이유

- **scale factor 는 비율로 씁니다** (F_k = s_k/s_기준 × F_기준). 원문 예처럼 기준이 1.0 이면 그대로 곱이 되고, 기준이 1.0 이 아니어도 같은 식으로 동작합니다.
- **추정은 크기 기준**입니다. FRF 표가 불러올 때 |H| 로 바뀌고 계측 표도 RPM·차수별 크기라 위상이 없으며, 단일 가진점이면 |H·F| = |H|·|F| 라 크기만으로 모형이 정확합니다. 여러 가진점이면 복소 기준이 필요해 수강생 확인 사항으로 남겼습니다.
- **다항식은 QR 분해로 풉니다.** 정규방정식은 조건수가 제곱으로 커져 3차 이상에서 불안정합니다. RPM 을 최댓값으로 나눠 풀고 계수를 되돌립니다.
- **1단계 방식(RPM·차수마다 따로)을 남겼습니다.** 새 추정의 그래프에 빈 원으로 겹쳐, 가정한 형태(scale 비·다항식 차수)가 계측과 맞는지 눈으로 볼 수 있게 했습니다.
- **추정 결과는 「RPM 연동 벡터」로 넘깁니다.** 표로 보여 고칠 수 있고, scale 고정 결과는 기준 차수 열만 넘겨 scale factor 가 그대로 이어집니다.
- 다항식 결과는 계측 RPM 범위 안에서만 벡터로 넘깁니다(외삽하면 값이 크게 틀릴 수 있어 화면에 경고).

## 판단과 이유

- **평균값 = 평균 제곱오차(RMS) 최소, 최대값 = 최대 절대오차 최소(minimax).** 원문 「전체 오차의 최대값 또는 평균값」을 모든 관측(지점·RPM·차수)의 오차로 읽었습니다. 「지점별 RMS 의 최대」일 가능성은 확인 사항으로 남겼습니다.
- **minimax 는 Lawson 반복 재가중**으로 풀었습니다. LP(단체법)보다 코드가 짧고 기존 QR 최소제곱을 그대로 쓰며, 손풀이 3건과 맞습니다. 비선형(overall 다항식)은 LM 을 안쪽에 두고 같은 재가중을 합니다.
- **overall + scale 고정은 선형**(overall = F_기준 × √Σ(|H|·비율)²)이라 닫힌 해/minimax 가 바로 됩니다. **overall + 다항식은 비선형**이라 LM 을 썼고, F_k 부호는 overall 로 구분되지 않아 양수로 맞춥니다.
- overall 로 맞출 때는 반공진 기준을 쓰지 않습니다 — |FRF| 로 나누지 않아 작은 |FRF| 에서 튀지 않습니다.
- **오차 단위(절대/상대)를 선택으로 더했습니다.** 최대값 기준은 절대오차면 공진 부근 큰 값에 끌려가기 쉬워, 계측 대비 비율로 맞출 수 있게 했습니다. 기본은 절대오차.
- 계측 표 형식은 「열 하나 = (지점, 차수|overall)」 배정 하나로 통일해, 형식이 늘어도 추정 코드는 그대로입니다. 배정 결과를 화면 표로 보여 줘 틀린 배치를 눈으로 잡을 수 있게 했습니다.

- **수강생 시안을 버리지 않고 기반으로 썼습니다.** 색·머리·카드 체계는 시안 그대로이고, 「빈 공간」은 hero 오른쪽이었으므로 그 자리를 개념도로 채웠습니다.
- **개념도는 실제 계산 순서 그대로입니다.** 캠벨의 주파수 축과 FRF 의 주파수 축을 같은 높이로 맞춰, 「가진 주파수 → 그 주파수의 |H| → 응답」이 점선 하나로 이어져 보이게 했습니다. 값은 가상 모형이라 그림 설명·코드 주석에 적었습니다.
- **카드 진입 애니메이션을 뺀 이유**: 이 도구는 버튼을 누를 때마다 화면 전체를 다시 그려, 카드가 매번 흐려졌다 나타났습니다.
- robots 는 과정 사본이라 noindex 로 두었습니다. 수강생 본인 배포본은 원하시는 대로 두시면 됩니다.
